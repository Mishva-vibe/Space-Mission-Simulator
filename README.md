# 🚀 Space Mission Simulator

**A Console-Based Space Survival Game Using Core Java and MySQL**

## 1. Project Overview

Space Mission Simulator is a console-based survival game developed using Core Java and MySQL. Players explore different planets, manage spaceship resources, collect valuable items, encounter aliens, and complete missions while maintaining fuel, oxygen, and health.

This project demonstrates the practical implementation of Object-Oriented Programming (OOP), Java programming concepts, game logic, and database connectivity using JDBC.

## 2. Project Objectives

- To apply Core Java and Object-Oriented Programming concepts.
- To develop an interactive console-based survival game.
- To implement spaceship resource management.
- To design planet exploration, alien combat, and mission systems.
- To integrate a Java application with a MySQL database using JDBC.

## 3. Key Features

- **Player Management:** Manage player details and scores.
- **Spaceship Management:** Monitor fuel, oxygen, and health.
- **Planet Exploration:** Explore different planets with varying difficulty levels.
- **Resource Collection:** Collect resources during exploration.
- **Alien Encounters:** Implement alien interactions and combat.
- **Mission System:** Complete missions and earn rewards.
- **Database Integration:** Store and retrieve game data using MySQL.

## 6. Database Design and Connectivity

The project uses MySQL to manage game-related data. JDBC (Java Database Connectivity) is used to establish communication between the Java application and the database.

The database setup script is named `space_mission_db.sql`.

**Database Setup Steps:**

1. Install and start MySQL Server.
2. Open MySQL Workbench.
3. Execute the `space_mission_db.sql` script.
4. Configure the database connection details in `DatabaseConnection.java`.
5. Add the MySQL Connector/J driver to the project dependencies.

## 7. How to Run the Project

**Prerequisites:** JDK, MySQL Server, MySQL Connector/J, and a Java IDE such as IntelliJ IDEA.

1. Download or clone the project repository.
2. Open the project in IntelliJ IDEA.
3. Configure the MySQL database.
4. Verify the database connection settings.
5. Ensure the JDBC driver is configured correctly.
6. Run `Main.java`.
7. Follow the console instructions to play the game.
